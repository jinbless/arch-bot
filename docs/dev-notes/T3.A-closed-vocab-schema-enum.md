## Architecture

```
[Hybrid Day 3 (이전)] partial 효과
   Vision LLM (gpt-4.1)
      ↓ schema axis enum (5 axes) + prompt enum 명시
      ↓ text는 free string (LLM이 MACHINERY/cooking 자유 출력)
   normalizer step → free-create는 unknown_codes 로 기록 (~0.2% 빈도)

         ↓ Tier 3.A 본격 적용

[T3.A (현재)]
   Vision LLM
      ↓ schema axis enum + **text enum 529 codes 강제**
      ↓ LLM이 catalog 밖 코드 출력 불가
   normalizer step → free-create 거의 0 (~0.1% 빈도, OpenAI edge-case 4건)
```

## Implementation

### `_load_catalog_codes()` (모듈 import 시 1회 로드)

```python
def _load_catalog_codes() -> list[str]:
    catalog_path = (
        Path(__file__).resolve().parents[1] / "data" / "risk_feature_catalog.json"
    )
    if not catalog_path.exists():
        return []
    data = json.loads(catalog_path.read_text(encoding="utf-8"))
    codes: set[str] = set()
    for axis_info in data.get("axes", {}).values():
        if isinstance(axis_info, dict):
            axis_codes = axis_info.get("codes", {}) or {}
            if isinstance(axis_codes, dict):
                codes.update(axis_codes.keys())
            elif isinstance(axis_codes, list):
                codes.update(axis_codes)
    return sorted(codes)

_ALL_CATALOG_CODES = _load_catalog_codes()  # module-level cache
```

### Schema enum 강제

```python
"text": (
    {"type": "string", "enum": _ALL_CATALOG_CODES}  # 529 codes
    if _ALL_CATALOG_CODES
    else {"type": "string"}  # fallback (catalog 없으면 free string)
),
```

Schema JSON 크기: 12.6KB (OpenAI strict mode 100KB 한도 내 충분).

## Known Limitations

| 항목 | 영향 | 대응 |
|---|---|---|
| OpenAI strict mode edge-case 4건 | THF/CO/MOBILE_EQUIPMENT/WAREHOUSE가 enum 밖 출력 (~0.4% 누락) | normalizer step 4.x에서 hard reject 가능 (Future Work) |
| Catalog 갱신 시 backend restart 필요 | module-level lazy load 1회 | catalog 변경 시 `make dev-restart` 호출 |
| LLM이 catalog 밖 사실을 표현 못 함 | 신규 산업/위험 발견 시 force `OTHER` 또는 누락 | F.1/F.2 자율 학습으로 catalog 확장 (이미 closed loop 운영) |
| Schema 12.6KB 증가 | OpenAI API request payload | 100KB 한도 대비 1/8 수준, 영향 미미 |

## Future Work (별도 plan)

- **잔존 4건 hard reject**: normalizer step에서 `_ALL_CATALOG_CODES` 검증, fallback `UNKNOWN`
- **잔존 4건 catalog 보강**: THF (테트라하이드로푸란)와 CO (일산화탄소)는 catalog 추가 후보. MOBILE_EQUIPMENT는 alias 등재로 해결 가능
- **Per-axis enum**: 현재 axis-text 페어링은 LLM 신뢰. strict 페어링 위해 `oneOf` per-axis (OpenAI strict 지원 시) 또는 sub-schema 분리
- **다른 sub-schema enum 확장**: `visual_cues.cue_type`은 이미 enum (6 옵션). `visual_observations.text`는 free string 유지 (자연어 서술 영역)

# 흐름 골격의 뒤 두 칸(종료·정기) 갭 진단 (2026-08-01)

[별표 파싱](../../data-team/01-parsing/rule-appendices/) 후 골격 6단계를 별표 3의 작업종류 19종에 돌린 결과,
앞 세 칸(계획·인적·작업 전)은 **19/19 전부 채워졌고** 뒤 두 칸만 남았다.

| 단계 | 빈 종류 |
|---|---|
| 계획 · 인적 · 작업 전 | **0/19** |
| 작업 중 | 1/19 (16 중량물 취급 — 원문에 절/관 좌표 없음) |
| 종료 | 10/19 |
| **정기** | **16/19** |

가설은 "기인물 → 대표 가이드 연결 품질 문제"였다. **틀렸다.**

## 검증 1 — SR 경로는 애초에 막혀 있다

`조문 → sr_article_mapping → wp_sr_mapping → work_processes → guide` 체인을 지게차 조문 13개로 확인:

```
지게차 조문의 SR            7개
그 SR 중 WP 연결            0개
wp_sr_mapping 총 SR       129개
sr_article_mapping 총 SR  626개  → 커버리지 20.6%
```

`wp_sr_mapping`이 SR의 20.6%만 덮고, 지게차 SR 7개는 거기 없다. 이 경로로는 대다수 기인물이 가이드에 닿지 못한다.

## 검증 2 — 가이드 본문 인용도 약하다

가이드 1,038개 전문에서 `안전보건규칙 제N조` 형태 인용을 세면 **204개(20%)** 뿐이다.
`guide_article_mapping`이 0행인 이유이기도 하다. 인용 기반 연결은 나머지 80%를 못 덮는다.

## 검증 3 — 가이드 집합으로 넓혀도 안 된다 (결정적)

"대표 가이드 1개" 대신 관련 가이드를 모두 모으면 될 것으로 봤다. 크레인으로 확인:

| 가이드 | 절차 수 | 정기 | 종료 |
|---|---|---|---|
| D-C-10-2026 건설장비 작업계획서 | 41 | **0** | 3 |
| B-M-9-2025 이동식크레인 양중작업 | 20 | **0** | 0 |
| M-82-2011 타워크레인의 설치 | 14 | **0** | 1 |
| B-M-34-2026 크레인 안전작업 | 6 | **0** | 0 |
| … 외 4개 | | **0** | |

**크레인 관련 가이드 8개 전부 정기점검 절차가 0이다.** 집합으로 넓혀도 채워지지 않는다.

## 진짜 원인 — 정기점검은 다른 법이 규율한다

전역 집계:

| | 값 |
|---|---|
| 정기 절차 보유 가이드 | 87 / 1,025 (**8.5%**) |
| 정기 절차 행수 | 114 / 9,316 (**1.2%**) |
| 규칙 조문 중 정기·검사 성격 | **4 / 669** (제115조 비파괴검사·제207조 조립해체 시 점검·제231조·제557조) |

산업안전보건기준규칙은 정기검사를 거의 규율하지 않는다. 그건 **산업안전보건법 제93조 안전검사**와
그 시행령·고시(안전검사 대상 기계 13종과 주기)가 맡는다. 우리 데이터셋(기준규칙 + KOSHA 가이드)에 그 원천이 없다.

즉 **정기 칸의 공백은 연결 버그가 아니라 데이터 원천 부재**다. 기인물→가이드 연결을 아무리 잘 고쳐도 안 채워진다.

## 종료 칸은 성격이 다르다

| | 값 |
|---|---|
| 종료 절차 보유 가이드 | 113 / 1,025 (11%) |
| 종료 절차 행수 | 176 / 9,316 |
| 규칙 조문 중 종료·이탈·해체 | **14 / 669** (제41조 운전위치 이탈금지 · 제99조 이탈 시 조치 · 제57조 비계 조립해체 · 제93조 방호장치 해체금지 등) |

조문이 14개 있으므로 **종료 칸은 채울 수 있다.** 다만 그 조문들이 기인물별 절/관에 흩어져 있어
현재 어휘 규칙(조문 제목 매칭)으로는 해당 기인물의 절에 없으면 못 잡는다.
제41조·제99조처럼 **총칙 성격의 이탈 조문을 전 기인물 공통으로 주입**하면 상당수가 해결된다
(지금은 제38·39·35조만 공통 주입 중).

## 결론과 선택지

1. **종료 칸** — 총칙 이탈·해체 조문(제41·99·93조 등)을 공통 주입한다. 코드 수정으로 해결. **권장**
2. **정기 칸** — 셋 중 하나:
   - (a) 골격에서 정기를 빼고 5단계로 간다. 데이터가 없는 칸을 비워두면 화면이 "정보 없음"만 반복한다
   - (b) **안전검사 대상·주기 데이터를 새로 확보**한다(산업안전보건법 시행령 제78조 + 안전검사 고시).
     대상 13종(크레인·리프트·프레스·전단기·압력용기·곤돌라·국소배기장치·원심기·롤러기·사출성형기·
     고소작업대·컨베이어·산업용 로봇)이 별표 3의 19종과 크게 겹쳐 조인 비용이 낮다. **정보 가치가 가장 큼**
   - (c) 정기 칸을 "안전검사 대상 여부"만 표시하는 안내 칸으로 축소한다
3. **기인물 → 가이드 연결** — 이번 진단으로 **우선순위가 내려갔다.** 종료·정기의 원인이 아니었고,
   작업 중 칸은 이미 조문으로 채워진다. 가이드는 절차 문구 보강용이지 골격 채움의 필수 경로가 아니다.

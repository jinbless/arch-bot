# 화재·폭발·위험물 누출 감독관 판단기준

> 재해유형 `FIRE_AND_EXPLOSION`. 물질 확인 → 보관·취급 제한 → 점화원·혼재·누출 차단 → 환기·검지 → 화기작업 허가.

  B --> C["[A] 제225: 위험물 취급시 폭발·화재·누출 방호(점화원 접근·가열·마찰·충격 금지)"]

- **제16조 [A]** 별도보관·필요량 · **제225조 [A]** 취급 방호 · **제230조~제232조 [A]** 폭발위험장소·환기·검지 · **제241조 [A]** 화재위험작업.
- **제234조 [A]** 가스등의 용기(감독관 gold 실측) — 용기 취급: 전도 방지(**세워두고 고정·체인/스트랩**)·충격 방지·캡/밸브 보호·화기 2m 이격·직사광선/40도↑ 장소 금지·산소와 가연성 분리 보관. 가스용기 방치·눕힘·미고정 단서 → 제234조.
- **제245조 [A]** 화기사용 장소의 화재 방지 — 화기(난로·버너 등) 사용 장소: 불연성 받침·주위 가연물 제거·소화기구. 겨울 현장 난로·취사 화기 단서.
- **제116조 [A·partial]** 압력방출장치(보일러·압력용기) — 안전밸브 설치·봉인 상태. 파열 예방.

## 실무 문구
인화성 물질 취급장소 화재위험작업 전 안전조치 미흡 → 보관 `[A]`제16 · 취급방호 `[A]`제225 · 폭발위험장소·환기 `[A]`제230~232 · 용접·절단 `[A]`제241.
가스용기 눕혀 방치·미고정·캡 없음 → `[A]`**제234조**. 난로·화기 주변 가연물 → `[A]`**제245조**. 보일러·압력용기 안전밸브 → `[A]`제116조.

- 가스용기(산소·LPG·아세틸렌) 단서 → **제234조** force-include. 난로·취사화기 → **제245조**. 보일러·압력용기 → 제116조·제119조.

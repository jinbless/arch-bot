# 업종별 prior 레이어 (분류축 아님 — 보정 + Guide 라우팅)

> **역할**: 업종은 SSOT 분류축이 아니라 **soft prior**다. ① 무관 재해형태 pruning(음식점→굴착/비계 기대 안 함) ② 재해형태/기인물 분류 가중치 보정 ③ **업종특화 KOSHA Guide 직접 선택**.
> Vision이 이미 `industry`를 추출 → 이 표로 예상 재해모듈(H··/E··) 활성 + 가이드 라우팅. **하드 게이트 금지**(틀려도 재해형태 분류가 주축).

## 사용 규칙 (④/⑤)
- Vision `industry` → 위 표로 **해당 재해모듈 후보 가중치 ↑** + **업종특화 Guide를 Guide 패널 후보에 추가**.
- 업종 신호 약하거나 없음 → prior 미적용(재해형태/기인물 분류만으로 진행 — recall 하한 보장).
- 업종이 명시하지 않은 재해형태도 분류되면 그대로 채택(prior는 가산점이지 필터 아님).

## 주의
- 같은 재해형태(추락·끼임)는 여러 업종에 공통 → 모듈은 재해형태로 1벌만 유지(중복 없음). 업종은 그 위에 얹는 라우팅.
- 영세 음식점 칼·믹서기·조리화상은 H04/H03/H11 모듈 + 본 표의 음식점 Guide로 커버(별도 "영세업종 모듈" 불필요).

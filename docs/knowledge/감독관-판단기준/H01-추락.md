# 추락재해 감독관 판단기준

> 재해유형 `FALL`. gold의 ~64%가 이 클러스터(제43:39·제13:15·제42:6·제56:8·제30:5·제68:5·제44·제45). Track A 최대 레버.
> `[A]`=가시(채점) · `[B]`=절차(자문).

## 핵심 구조
```
① 추락위험 장소인가?
→ ② 위험유형(시설) 특정: 작업발판·계단·사다리식 통로·가설통로·개구부·비계·이동식비계·지붕
→ ③ 시설별 1차 방호조치 적용
→ ④ 설치 곤란/임시해체 시 대체조치 (방호망→안전대)
→ ⑤ 안전대 사용 시 부착설비+사전점검 (제44)
```

## 조문별 선후관계
- **제42조 [A·partial]** 일반 추락 — 작업발판 우선 → 곤란시 추락방호망(수직거리 10m↓·수평·처짐·내민길이) → 곤란시 안전대 → **제44조**로 연결.
- **제43조 [A·yes]** 개구부·통로끝·작업발판끝 — 난간·울타리·수직형방망·덮개(충분한 강도). 덮개는 뒤집힘·탈락 방지 + 식별표시. 설치곤란/임시해체 시 제42 방호망 → 안전대. (제42보다 장소특정형)
- **제44조 [A·partial]** 안전대는 끝이 아님 — 높이 2m↑서 안전대 착용 시 부착설비 설치 + 지지로프 처짐·풀림 방지 + 작업 전 점검(이상시 보수·교체).
- **제30조 [A·yes]** 높이 1m↑ 계단 개방측 **난간 없음 → 제30조**(설치 의무 위반).
- **제13조 [A·partial]** 안전난간 구조기준 — ★**난간이 있으나** 구조(상부·중간난간대·발끝막이판10cm↑·난간기둥·100kg) 미달일 때만 **제13조**. 난간 없으면 장소조문(계단 제30·개구부 제43·비계 제56·이동식 제68). **단독 1차 금지 — 난간 존재가 전제**(감독관 검수 `방호조치 대체 관련.pdf`).
- **제56조 [A·partial]** 비계 작업발판(폭·틈·고정·견고성·안전난간) → 난간 구조 제13. "아시바 1줄만" = 제56 난간 미흡 + 제13.
- **제68조 [A·partial]** 이동식비계(바퀴 브레이크·전도방지·승강사다리·최상부 난간·수평·250kg).
- **제45조 [A·yes]** 지붕 위 작업 위험 방지.
- **제24조 [A·partial]** 사다리식 통로 구조 — 견고·손상없는 재료·발판간격 일정·벽과 15cm·**폭 30cm↑**·넘어짐/미끄러짐 방지·**상단 60cm↑ 돌출**·길이 10m↑면 5m마다 계단참·**기울기 75도↓**(고정식 90도↓ 별도). 사다리 자체가 추락 경로 = 위험장소 유형(감독관 gold 검수로 확인, 2026-07-30).
- **제23조 [A·partial]** 가설통로 구조 — 견고·경사 30도↓·15도 초과시 미끄럼방지·**추락위험 장소 안전난간**(→ 난간 구조는 제13조 분기)·수직갱 15m↑면 10m마다 계단참.
- **제26조~제29조 [흐름]** 계단 구조(강도·폭 1m↑·계단참·천장높이) — 계단 식별 後 점검 흐름.

## 적용순서 (사진 유형별)
- **계단(1m↑ 개방측)**: 난간 **없음 → 제30**(미설치) / 난간 **있고 구조미달 → 제13**(구조) — 배타·조건부(택일) → (계단참·통로끝 개구부) 제43.
- **개구부/통로끝**: 제43 → (덮개) 고정+표시 / (난간) 제13 / (곤란·임시해체) 제42 방호망 → 안전대 제44.
- **비계 작업발판**: 제56(발판 기준) → 추락위험장소 난간 → 제13 구조 → (자재낙하 동반) 제14.
- **이동식비계**: 제68 → 최상부 난간 제13 → (적재) 250kg / (자재낙하) 제14.
- **사다리식 통로**: 제24(폭·미끄러짐·상단 60cm·기울기) → (이동식 사다리 작업은 별도) / 통행용 구조 판단이 핵심.
- **가설통로·경사로**: 제23(경사·미끄럼방지) → (추락위험 구간) 안전난간 → 구조 제13.

## 실무 판단 문구 예
- 개구부 방호덮개 고정 불량 및 식별표시 미흡 → 주 **제43**, 난간이면 **제13**, 곤란·임시해체 시 **제42/44**.
- 비계 외측 아시바 1줄 → 주 **제56**, 난간구조 **제13**, 자재낙하 **제14**.
- 사다리식 통로 발판 간격 불규칙·폭 30cm 미만·상단 미돌출·미끄럼방지 없음 → 주 **제24**.
- 경사 가설통로 미끄럼방지 없음·추락 구간 난간 없음 → 주 **제23**, 난간구조 **제13**.
- 계단 1m↑ 개방측 **난간 없음 → 제30**(미설치) · 난간 **있고 구조미달 → 제13**(구조) [택일], 계단참 개구부면 **제43**.

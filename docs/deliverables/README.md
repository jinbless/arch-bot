## 외부 보관

최종보고서 PDF 본문은 root git에 포함되지 않는다. 로컬 또는 외부 저장소에 보관하며 필요 시 별도 채널로 공유한다.

## 정책

신규 산출물 추가 시:

1. 본문이 5MB를 초과하는 바이너리(PDF 등)는 root git에 직접 추적하지 않는다. 외부 보관 + 매니페스트 참조 방식을 사용한다.
2. 핵심 요약/메타데이터 마크다운은 여기에 추적한다.
3. `data-team/05-enrichment/eval-data/reports/**`처럼 평가 보고서 본문이 아닌, 최종 연구 산출물만 여기에 둔다.

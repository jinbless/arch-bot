예시 쿼리 (현재 v2/risk 구조 기준, 복사해서 위 에디터에 붙여넣기)

주요 클래스별 인스턴스 수 
PREFIX law: <https://cashtoss.info/ontology/law#>
PREFIX sr: <https://cashtoss.info/ontology/sr#>
PREFIX guide: <https://cashtoss.info/ontology/guide#>
PREFIX pen: <https://cashtoss.info/ontology/penalty#>
SELECT ?className (COUNT(?s) AS ?cnt) WHERE {
  VALUES (?className ?type) {
    ("Article" law:Article)
    ("NormStatement" law:NormStatement)
    ("SafetyRequirement" sr:SafetyRequirement)
    ("KoshaGuide" guide:KoshaGuide)
    ("ChecklistItem" guide:ChecklistItem)
    ("PenaltyRule" pen:PenaltyRule)
  }
  ?s a ?type .
} GROUP BY ?className ORDER BY DESC(?cnt)
의무이행주체(DutyHolder)별 의무 NormStatement 수 
PREFIX law: <https://cashtoss.info/ontology/law#>
PREFIX core: <https://cashtoss.info/ontology#>
PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#>
SELECT ?roleName (COUNT(?ns) AS ?cnt) WHERE {
  ?ns a law:NormStatement ;
      law:hasModality core:Obligation ;
      law:hasSubjectRole ?role .
  ?role a core:DutyHolder ;
        rdfs:label ?roleName .
  FILTER(LANG(?roleName) = "ko")
} GROUP BY ?roleName ORDER BY DESC(?cnt)
risk:RiskFeature 하위 위험 분류 클래스 
PREFIX risk: <https://cashtoss.info/ontology/risk#>
PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#>
SELECT ?featureClass ?label WHERE {
  ?featureClass rdfs:subClassOf risk:RiskFeature .
  FILTER(STRSTARTS(STR(?featureClass), "https://cashtoss.info/ontology/risk/"))
  OPTIONAL { ?featureClass rdfs:label ?label . FILTER(LANG(?label) = "ko") }
} ORDER BY ?featureClass

3축 전체 분포 (AccidentType × Agent × WorkContext) 
PREFIX sr: <https://cashtoss.info/ontology/sr#>
PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#>
SELECT ?atLabel ?agLabel ?wcLabel (COUNT(?sr) AS ?cnt) WHERE {
  ?sr a sr:SafetyRequirement ;
      sr:addressesAccidentType ?at ;
      sr:addressesAgent ?ag ;
      sr:inWorkContext ?wc .
  ?at rdfs:label ?atLabel . FILTER(LANG(?atLabel)="ko")
  ?ag rdfs:label ?agLabel . FILTER(LANG(?agLabel)="ko")
  ?wc rdfs:label ?wcLabel . FILTER(LANG(?wcLabel)="ko")
} GROUP BY ?atLabel ?agLabel ?wcLabel ORDER BY DESC(?cnt) LIMIT 20
가이드별 CI-SR 연결률 
PREFIX guide: <https://cashtoss.info/ontology/guide#>
PREFIX core: <https://cashtoss.info/ontology#>
SELECT ?guideCode ?guideTitle (COUNT(?ci) AS ?totalCI) (COUNT(?sr) AS ?linkedCI) WHERE {
  ?g a guide:KoshaGuide ;
     guide:guideCode ?guideCode ;
     core:title ?guideTitle ;
     guide:hasChecklistItem ?ci .
  OPTIONAL { ?ci guide:basedOnSR ?sr }
} GROUP BY ?guideCode ?guideTitle ORDER BY DESC(?totalCI) LIMIT 20
가이드 CI → SR → 조문 → PenaltyRule 추적 
PREFIX guide: <https://cashtoss.info/ontology/guide#>
PREFIX sr: <https://cashtoss.info/ontology/sr#>
PREFIX law: <https://cashtoss.info/ontology/law#>
PREFIX pen: <https://cashtoss.info/ontology/penalty#>
PREFIX core: <https://cashtoss.info/ontology#>
SELECT ?ciId ?srId ?artCode ?penalty WHERE {
  ?ci a guide:ChecklistItem ;
      core:identifier ?ciId ;
      guide:basedOnSR ?sr .
  ?sr core:identifier ?srId ;
      sr:derivedFromNS ?ns .
  ?ns law:hasSourceArticle ?art ;
      pen:hasPenaltyRule ?pr .
  ?art law:articleCode ?artCode .
  ?pr pen:hasSanction ?san .
  ?san pen:penaltyDescription ?penalty .
} LIMIT 20
제42조 위반 시 법적 결과 추적 
PREFIX law: <https://cashtoss.info/ontology/law#>
PREFIX sr: <https://cashtoss.info/ontology/sr#>
PREFIX pen: <https://cashtoss.info/ontology/penalty#>
PREFIX core: <https://cashtoss.info/ontology#>
PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#>
PREFIX xsd: <http://www.w3.org/2001/XMLSchema#>
SELECT DISTINCT ?srId ?riskLabel ?penaltyDesc ?severity WHERE {
  ?art law:articleCode "제42조"^^xsd:string ;
       law:hasLawType law:LawType_RULE .
  ?ns law:hasSourceArticle ?art .
  ?sr sr:derivedFromNS ?ns ;
      core:identifier ?srId .
  OPTIONAL {
    ?sr sr:addressesHazard|sr:addressesAccidentType ?risk .
    ?risk rdfs:label ?riskLabel .
    FILTER(LANG(?riskLabel) = "ko")
  }
  ?ns pen:hasPenaltyRule ?pr .
  ?pr pen:hasSanction ?san .
  ?san pen:penaltyDescription ?penaltyDesc ;
       pen:severityScore ?severity .
} ORDER BY DESC(?severity) LIMIT 20
PenaltyRule 샘플 — 위반 조문과 실제 벌칙 조문 분리 
PREFIX pen: <https://cashtoss.info/ontology/penalty#>
PREFIX law: <https://cashtoss.info/ontology/law#>
SELECT ?pr ?violatedCode ?penaltyCode ?penaltyDesc WHERE {
  ?pr a pen:PenaltyRule ;
      pen:violatedArticle ?violatedArticle ;
      pen:penaltyArticle ?penaltyArticle ;
      pen:hasSanction ?sanction .
  ?violatedArticle law:articleCode ?violatedCode .
  ?penaltyArticle law:articleCode ?penaltyCode .
  ?sanction pen:penaltyDescription ?penaltyDesc .
} LIMIT 20

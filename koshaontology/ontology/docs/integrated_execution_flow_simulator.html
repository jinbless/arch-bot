OHS × Ontology 통합 실행 흐름 시뮬레이터 (Faceted 3축)

Faceted 3축 분류 체계 (AccidentType 8종 × HazardousAgent 11종 × WorkContext 13종)를 중심으로, 사용자 입력이 어떻게 관찰 → Faceted 축 매핑 → 온톨로지 추론 → 결정론적 체크리스트/벌칙 경로로 변환되는지 동적으로 보여줍니다.
파랑: OHS/GPT 관찰 계층 (Track A) 노랑: Faceted 3축 매핑 (Track B) 초록: 온톨로지/PG+Fuseki 추론 빨강: 위반/벌칙 경로 + Divergence 감지 보라: 최종 사용자 응답

시나리오 선택

현재 계획의 설계 원칙

1. GPT는 위험 발견/설명 (Track A 자유 분석) 2. Faceted 3축으로 매핑 (AccidentType × Agent × WorkContext) 3. SR/CI/Penalty는 faceted 축 조합으로 조회 4. 체크리스트는 결정론적으로 생성 5. Track A↔B Divergence 감지 및 판정

왜 구조를 바꿔야 하나

기존엔 OHS의 GPT 분류(flat 24종)와 법령/온톨로지 분류(12종)가 달라서 중간 브리지 로직에 의존했습니다. Faceted 3축 체계는 이를 제거하고 사고유형 × 유해인자 × 작업맥락 조합으로 정밀 매핑합니다. GPT Track A(자유 분석)와 Track B(faceted 축)를 병행해 divergence를 감지합니다.

현재 시나리오 핵심 코드

단계 진행도

각 단계는 단순 설명이 아니라, 실제 구현 시 필요한 데이터 흐름 (관찰 facts, canonical hazard code, SR/CI/SPARQL 결과, 위반 판정, 벌칙 경로)를 기준으로 구성되어 있습니다.

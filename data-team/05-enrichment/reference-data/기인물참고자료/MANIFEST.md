## 핵심 통계
- SIF distinct 기인물 **677종**. top: 지게차 216·비계 196·굴착기 186·고소작업대 173·지붕채광판 167·사다리 165·철골 156·지붕 146·트럭 122·슬라브단부 121·거푸집 102·달비계 95·이동식비계 92·크레인 76.
- **감소대책의 52% / 예방조치의 46%가 법정 조치어휘**(덮개·울·방호장치·난간·안전대·추락방호망·비상정지·접지…) 직접 포함 → 조문 매핑 신호 강함.

## per-file 가치 검증 (2026-06-21, 실제 확인)
- **SIF xlsx / 구조화 MD = 금광** (case-level 기인물+조치, 직접 활용). 전량 파싱·통계 검증.
- **기인물_사례별.csv / 교차표·품목빈도 CSV / 요약.md = 보조** (1,177건 집계·빈도·세분). alias 사전·우선순위용. 교차표=요약과 동일, 품목빈도=요약의 전체판.
- **PDF = 방법론/참고 (금광 아님)**. 2011 **집계 통계**(사례 아님) + 공식 KOSHA 기인물 2~3단계 분류체계(설비기계>운반인양/일반제조가공/건설광산용; 건축구조물>비계/단부개구부/계단사다리…). 스캔 이미지. SIF/구조화(최신·case-level)가 상위 → **직접 데이터 가치 없음, alias 카테고리 정렬 보조만.**
